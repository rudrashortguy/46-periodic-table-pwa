# ElementScope - Interactive Periodic Table

Explore chemical elements, atomic properties, electron configurations, and periodic trends interactively.

## Features
- Interactive periodic table grid
- Detailed element property cards
- Category color coding
- Search & filter by properties

## Tech Stack
- **Vite** & **React 18** with TypeScript
- **Tailwind CSS** for responsive mobile-first styling
- **Workbox / Vite PWA Plugin** for offline caching & service worker lifecycle

## Development
```bash
npm install
npm run dev
```
